<h1 align="center"> ICS3U/C Codespace Startup </h1>
<img src="https://github.com/Mr-Coxall/ICS3U-Codespace-Startup/raw/main/images/github-codespaces.png" alt="github-codespaces" class="center">

Use this GitHub repo to setup an ICS3U/C Codespace.

It includes everything you will need to code in Python and C/C++.

To create your Codespace instance:
<ul>
<li>Log into your GitHub student account.</li>
<li>Click on <img src="https://github.com/LynnetteR/ICS3U-Codespace-Startup/raw/main/images/use this template.png" alt="Use this template" class="center"></li>
</ul>

Once you have arrived at this page, in the terminal type:
<ul>
<li><b>sh ./setup.sh</b></li>
<li>then follow the prompts to finish setting up your new Codespace and connect it to your GitHub account</li>
</ul>
